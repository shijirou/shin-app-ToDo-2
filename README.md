**選定理由（指示で決まっていないもの）**
- TypeScript: React と組み合わせるときの標準的な言語。型があるので、Java と同じくミスに早く気づける
- Vite: React の開発環境を作る標準的なツール（Next.js を使わない場合の定番）
- dnd-kit: React 向けのドラッグ&ドロップ用ライブラリ（vuedraggable は Vue.js 用のため不採用）
- Tailwind CSS: HTML（React の部品）に短い名前（例: `p-4` `bg-white`）を並べるだけで見た目を整えられるため、CSS ファイルを別に書く手間が減る。React + Vite と組み合わせて使う例が多い。プロトタイプの style.css はそのまま使わず、見た目を参考にして書き直す
- Spring Data JPA: Spring Boot から PostgreSQL を読み書きする標準的な方法
- npm: React / Vite に最初から付いてくる標準のパッケージ管理ツール
- Gradle: Spring Boot の公式ひな形作成サイト（Spring Initializr）で標準的に選べるビルドツール。設定ファイルが短く読みやすい。「Gradle Wrapper」が付いてくるため、Gradle 本体を別途インストールしなくてよい

### ユースケース
代表的な例を記載しています。

<a id="uc-1"></a>
**1. カードを追加する**
- 主アクター: ユーザー
- 基本フロー:
  1. 「カードを追加」から追加モーダルを開く
  2. 追加先リストを選択する
  3. カードの内容を入力する
  4. 「追加」ボタンを押す
  5. 選択したリストの末尾にカードが追加され、データベースに保存される
- 異常系: 内容が空文字の場合はエラーとなり、追加できない

<a id="uc-2"></a>
**2. カードをドラッグ&ドロップで移動する**
- 主アクター: ユーザー
- 基本フロー:
  1. 移動したいカードをドラッグする
  2. 同じリスト内の別の位置、または別のリストにドロップする
  3. カードの並び順・所属リストが更新され、データベースに即時保存される
- 異常系: リストの外側など、ドロップ不可能な場所に落とした場合は移動前の位置に戻る

<a id="uc-3"></a>
**3. リストを削除する（カード入り）**
- 主アクター: ユーザー
- 基本フロー:
  1. リストヘッダーの「…」メニューから「リストを削除」を選ぶ
  2. 確認ダイアログが表示される
  3. 「OK」を選ぶとリストと中のカードがすべて削除され、データベースに保存される
- 異常系: 確認ダイアログで「キャンセル」を選んだ場合、リストは削除されず何も変わらない

### 非機能要件
- **対応ブラウザ**: 最新版のChrome / Edge / Firefoxを想定
- **レスポンシブ対応**: PCブラウザ専用（スマホ・タブレット対応は対象外。ドラッグ&ドロップもマウス操作を前提とする）
- **想定規模（パフォーマンス目安）**: 小規模利用を想定（リストは数件程度、カードはリストごとに数十件程度）。大量データ向けの性能最適化は行わない
- **データ永続化**: データはサーバー上のPostgreSQLに保存する。ブラウザを閉じたり、ブラウザのデータ（キャッシュ・サイトデータ）を消去したりしても保存内容は残る
- **動作環境の前提**: 利用時はバックエンド（Spring Boot）とデータベース（PostgreSQL）を起動しておく必要がある。当面は自分のPC上（ローカル環境）で動かすことを想定し、インターネット上への公開は対象外とする
