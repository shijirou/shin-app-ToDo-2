### 要件定義（確定）
**アプリ名**: Trello風タスクボード

**機能一覧**
1. リストの追加
2. リストの名前編集
3. リストの削除
4. カードの追加（リスト内）
5. カードの内容編集
6. カードの削除
7. カードをドラッグ&ドロップで並び替え・別リストへ移動
8. データはlocalStorageに保存し、再読み込みしても消えない

**技術構成**
- HTML / CSS / JavaScript（素の構成、フレームワークなし）
- ファイルは index.html / style.css / app.js の3つ
- データ永続化: ブラウザのlocalStorageのみ（サーバー・DBなし）

**対象外（今回作らない）**
- ログイン機能
- 複数ボード
- ラベル・期限・添付ファイルなどの高度な機能

### ユースケース（代表例）

**1. カードを追加する**
- 主アクター: ユーザー
- 基本フロー:
  1. 「カードを追加」から追加モーダルを開く
  2. 追加先リストを選択する
  3. カードの内容を入力する
  4. 「追加」ボタンを押す
  5. 選択したリストの末尾にカードが追加され、localStorageに保存される
- 異常系: 内容が空文字の場合はエラーとなり、追加できない

**2. カードをドラッグ&ドロップで移動する**
- 主アクター: ユーザー
- 基本フロー:
  1. 移動したいカードをドラッグする
  2. 同じリスト内の別の位置、または別のリストにドロップする
  3. カードの並び順・所属リストが更新され、localStorageに即時保存される
- 異常系: リストの外側など、ドロップ不可能な場所に落とした場合は移動前の位置に戻る

**3. リストを削除する（カード入り）**
- 主アクター: ユーザー
- 基本フロー:
  1. リストヘッダーの「…」メニューから「リストを削除」を選ぶ
  2. 確認ダイアログが表示される
  3. 「OK」を選ぶとリストと中のカードがすべて削除され、localStorageに保存される
- 異常系: 確認ダイアログで「キャンセル」を選んだ場合、リストは削除されず何も変わらない

### 非機能要件
- **対応ブラウザ**: 最新版のChrome / Edge / Firefoxを想定
- **レスポンシブ対応**: PCブラウザ専用（スマホ・タブレット対応は対象外。ドラッグ&ドロップもマウス操作を前提とする）
- **想定規模（パフォーマンス目安）**: 小規模利用を想定（リストは数件程度、カードはリストごとに数十件程度）。大量データ向けの性能最適化は行わない
- **データ永続化の制約**: 同一ブラウザ・同一端末のlocalStorageにのみ保存する。他端末・他ブラウザとは同期しない。ブラウザのデータ（キャッシュ・サイトデータ）を消去すると保存内容も失われる
